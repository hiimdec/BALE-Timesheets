Mobile · Day-first One screen per day with crew listed. Tap to drill into per-person edits. Recommended for phone use.

Toggle, don't hide. The mode lives in Production Settings as an explicit choice — both options described clearly. New productions default to Mobile, but flipping to Grid mode is one tap. Same data; just a different rendering. Existing Best Boy productions migrate as Mobile by default but can flip immediately.
